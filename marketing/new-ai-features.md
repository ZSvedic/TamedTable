# New AI feature list

A reworked "What you can do" menu for the marketing brief, leading with the
killer feature: the LLM reads each row's context the way a person would, so it
does things no Excel formula or feature can. The everyday spreadsheet operations
are still here, but they no longer headline — the AI rows do.

Three columns: a category, the capability (phrased to carry the AI angle), and
the plain-language request a user would type or say.

| Category | What you can do | In your words |
|---|---|---|
| Clean up | Normalize phone numbers by Country | *"normalize the phone numbers"* |
| Clean up | Merge spelling variants into one | *"make the country names consistent"* |
| Clean up | Title-case even tricky names | *"fix the capitalization of names"* |
| Clean up | Parse messy dates into one format | *"clean up the birth dates"* |
| Enrich | Fill the country from the city | *"fill the country from the city column"* |
| Enrich | Add a continent or region | *"add a continent column"* |
| Enrich | Guess a company's industry from its name | *"add the industry for each company"* |
| Classify | Tag tickets by type | *"label each ticket as billing, bug, or feature"* |
| Classify | Score review sentiment | *"score the sentiment of every review"* |
| Classify | Rank titles by seniority | *"sort the titles by seniority"* |
| Classify | Group by inferred gender | *"split customers into men and women"* |
| Extract | Split an address into parts | *"split the address into its parts"* |
| Extract | Split a full name | *"split the full names"* |
| Extract | Pull amount and date from a note | *"extract the amount and date from the memo"* |
| Validate | Flag impossible birth dates | *"flag any impossible birth date"* |
| Validate | Flag city/country mismatches | *"check the city matches the country"* |
| Language | Translate a column in place | *"translate the comments to English"* |
| Language | Summarize long text into a line | *"summarize each review in one line"* |
| Language | Detect each row's language | *"tag the language of every comment"* |
| Language | Ask in your own language | *"normaliza los números de teléfono"* |
| Everyday | Keep only the rows you want | *"keep only customers in the USA"* |
| Everyday | Sort, or take the top few | *"sort by revenue, top 10"* |
| Everyday | Drop duplicate rows | *"remove duplicate emails"* |
| Everyday | Reshape tall to wide | *"pivot months into columns"* |
| Everyday | Combine two tables | *"add each order's customer name"* |
| Save & reuse | Save cleaned data as CSV or JSONL | `:save clean.csv` |
| Save & reuse | Save the recipe, replay free | `:save-flow tidy.flow` |
| Save & reuse | Export a Python script | `:save-py tidy.py` |
| Save & reuse | Undo or redo any change | `:undo` / `:redo` |
| Open & run | Open a file in browser or CLI | a file or a URL |
