Privacy Policy and Data Processing

TamedTable's privacy policy is intentionally short and simple, so you can read and understand it in two minutes.

We don't have a server and we don't use any cookies. The TamedTable app is client-side JavaScript, running in your browser. That is also why you have to enter your API keys again whenever you switch browsers: your settings don't leave your browser.

There is no separate EULA: TamedTable is source-available (BUSL), so your use is governed by its license on GitHub.

That said, some third-party servers are involved:

Hosting

TamedTable is hosted on GitHub Pages. The visitor's IP address is logged and stored for security purposes, the same as every other server on the internet. For more information, see the GitHub Privacy Statement.

Analytics

TamedTable uses Umami, a privacy-first analytics platform. It aggregates analytics without cookies, surveillance, or selling your data to third parties. For more information, see the Umami Privacy Policy.

Every visit records page views only: the page path, the referrer, and the coarse browser/OS/device class and country Umami derives on its servers. It sets no cookies and stores no identifier that could follow you across visits or sites.

Inside the web app, a handful of named events count feature use. An event is a name plus, at most, one coarse label from a fixed list. Events never carry file names, file contents, table values, chat or voice text, API keys, or anything else you type: there is nothing more to an event than what this table says.

EventFires whenProperties
open-fileA table is opened.source: local, url, sample, or drop
open-flowA saved flow is replayed onto the current table.—
chat-requestA typed request is sent to the model.—
voice-requestA spoken request is sent to the model.—
undo / redoHistory is stepped back or forward.—
run-all"Run on all rows" evaluates the pending AI cells.—
save-dataThe table is saved to a file.format: csv, jsonl, parquet, or arrow
save-flowThe flow is saved for later replay.—
export-pythonThe flow is exported as a Python script.—
tutorial-playA guided tour starts.tour: the tour's name (fixed app content)
connect-providerAn API key is verified and its provider connected.provider: the provider's name, never the key

The event names and the code that sends them are open source: analytics.ts is the single wrapper every event goes through.

If, for whatever reason, you don't like GitHub or Umami, there is a solution. TamedTable's source code is public on GitHub, so you can fork the repo, tell your coding agent to remove any analytics, and host it yourself.

Optional third-party servers

TamedTable is an AI ETL, where "AI" means your chat requests are sent to an LLM provider of your choice. You need to check the policy only for the providers you actually call:

  • Google (Gemini): Privacy Policy
  • OpenAI: Privacy Policy
  • Anthropic: Privacy Policy
  • OpenRouter: Privacy Policy
  • Groq: Privacy Policy

If, for whatever reason, you are not comfortable with any of the listed providers, there is a solution. TamedTable's source code is public on GitHub, so you can fork the repo, tell your coding agent to use a local or internal LLM instead, and host it yourself.
