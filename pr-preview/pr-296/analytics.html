Analytics, in public

TamedTable uses cookie-less analytics, and hides nothing about them: this page lists everything the site tracks, and the live dashboard below shows the same numbers we see. What reaches the analytics is anonymous page views and feature counts; your data and your keys stay with you.

Live dashboard

The Umami dashboard for www.tamedtable.com is public: the same page views and event counts the maintainers see, live, for anyone who opens it.

The public share link is being set up: check back shortly. Until then, the tables below still list everything that is tracked.

What every visit records

Page views only: the page path, the referrer, and the coarse browser/OS/device class and country Umami derives on its servers. Umami sets no cookies and stores no identifier that could follow you across visits or sites. The site also carries Cloudflare's cookie-less Web Analytics beacon, which records the same page-view level and nothing more.

The full event list

Inside the web app, a handful of named events count feature usage. An event is a name plus, at most, one coarse label from a fixed list, shown in full below. Events never carry file names, file contents, table values, chat or voice text, API keys, or anything else you type: there is nothing more to an event than what this table says.

EventFires whenProperties
open-fileA table is opened.source: local, url, sample, or drop
open-flowA saved flow is replayed onto the current table.—
chat-requestA typed request is sent to the model.—
voice-requestA spoken request is sent to the model.—
undo / redoHistory is stepped back or forward.—
run-all"Run on all rows" evaluates the pending AI cells.—
save-dataThe table is saved to a file.format: csv, jsonl, parquet, or arrow
save-flowThe flow is saved for later replay.—
export-pythonThe flow is exported as a Python script.—
tutorial-playA guided tour starts.tour: the tour's name (fixed app content)
connect-providerAn API key is verified and its provider connected.provider: the provider's name, never the key

The event names and the code that sends them are open source: analytics.ts is the single wrapper every event goes through.
