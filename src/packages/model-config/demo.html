model-config: ModelChooser & resolveConfig

Paste an API key and press Add; its prefix names the provider, and that provider's chat and cell models are fixed defaults shown with their measured cost and speed. The resolved config updates live, and config is shared with the main app via localStorage.

The chooser above runs against a stub provider, so any key with a recognised prefix connects and no real account is billed. The test-call box at the bottom is the live one: it issues a real call to the selected model with the key you entered.
