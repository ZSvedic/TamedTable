## Findings (need follow-up — out of scope for a docs cleanup)

1. **Web missing-key guard regression (`web.feature` scenarios 12 & 21).** The spec says a text request with no Anthropic key surfaces a toast and makes *no* request; `controller-engine.ts` instead initialises the SDK with a placeholder key and lets the API error surface (lines 57–60). Offline that yields `no recording for this request` rather than the expected toast, and the spec is mutated. Fixing it is a behavior change (spec → test → impl, plus a cassette re-record) — a separate PR.

2. **Stale cell-model default `claude-sonnet-4-5`.** `headless/index.ts` defaults `TAMEDTABLE_CELL_MODEL` to `claude-sonnet-4-5`, documented identically in `README.md` and `code-contract.md` — but the verified catalogue (`model-config/models.json`) lists only `claude-sonnet-4-6` and `claude-haiku-4-5`. The docs match the code, so there is no doc-doc mismatch to fix here; aligning the default to a catalogued id is a behavior change (it shifts cell-call fingerprints and needs a cassette re-record) — a separate PR.
